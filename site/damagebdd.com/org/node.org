* Updating Damage Node (Very Easy)

When a new version is released:

1. Visit this page  
2. Download the new file  
3. Install it the same way as before  

You do *not* need to uninstall the old version.
The new version replaces it automatically.

All of your:

- settings  
- data  
- keys  

remain intact.

* What Makes DamageBDD Distribution Trustless?

Damage Node installers are stored on **IPFS**, which means:

- No single company controls distribution  
- Anyone can mirror the files  
- Downloads are verified by cryptographic content addressing  
- Files cannot be secretly changed — the CID would change  

This is the same decentralisation philosophy as Bitcoin.

* Next Steps: Node Administration

Running a DamageBDD node goes beyond basic execution.  
To operate reliably in production, every node requires correct configuration of:

- Admin wallets (custodial or non-custodial)
- Bitcoin + Lightning (CLN) connectivity
- LNURL / Lightning Address routing
- Nostr relay integration
- Execution security through =erlexec=
- Privilege isolation and secret management

These responsibilities are covered in the companion document  
[[./node_admins][Node Admins]], which provides a focused operational guide for system administrators.
