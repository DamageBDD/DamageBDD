# DamageBDD mobile

Vanilla HTML/CSS/JavaScript client for:

- `GET /version/`
- `POST /accounts/auth/`
- `PUT /execute_feature/`

```sh
make init
make run
make log
```

Edit files under `src/`. `www/` is generated by `npm run web` and should not be edited.

The access token is session-only in this skeleton. Replace the session storage adapter with Android Keystore before relying on long-lived credentials.
