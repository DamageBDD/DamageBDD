# 🥪 sandwich

Deterministic sandwich minting.

No guessing.  
No AI hallucinations.  
Only state recovery.

---

## What Is This?

`sandwich` is a minimal deterministic mint + retrieval demo inspired by ECAI principles:

> encode → structure → store → retrieve

Each sandwich is:

- Canonically encoded
- Hashed with SHA-256
- Assigned a deterministic Token ID
- Mapped to a structured “curve point”
- Stored in an append-only ledger

The same inputs always produce the same sandwich token.
