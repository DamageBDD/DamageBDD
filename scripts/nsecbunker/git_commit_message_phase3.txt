feat(nsecbunker): add Phase 3 relay NIP46 bridge

Add the relay-facing Phase 3 bridge for encrypted NIP46 flow using disposable
keys. The relay client accepts inbound kind:24133 events, passes them to the
nsecbunker encrypted handler, receives a signed response event, and then
attempts relay publication as a separate concern.

The bunker signing decision remains independent of relay publication success.
BDD and EUnit coverage verify subscription filter shape, p-tag targeting,
return-only publication, and publication-failure isolation.

LodgeiT key ceremony remains out of scope until Phase 4.
